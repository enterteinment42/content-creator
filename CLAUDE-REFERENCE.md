# content-creator — справочник

Устройство: структура снапшота, что портируем из магазина, UI-концепция, стиль,
методика журнала самообучения. Вынесено из `CLAUDE.md` 22.09.2026, в автозагрузку
не входит, читается по необходимости.

---

## Структура игры в снапшоте

```javascript
{
  title: "Spider-Man 2",
  priceRUB: 2500,
  discount: 30,          // процент скидки или null
  icon: "https://...",   // обложка IGDB (t_cover_big)
  featuredImg: "...",    // featured image (если есть)
  description: "...",
  store: "PS",
  hidden: false,
  selected: false        // игнорировать, это UI-флаг
}
```

## Что портируем из основного магазина

| Модуль | Источник | Объём |
|--------|----------|-------|
| Таблица игр с галочками | `js/admin-core.js` (renderAdminTable) | ~150 строк |
| Коллаж | `js/collage.js` | ~500 строк |
| Сторис | `js/story.js` | ~??? строк |
| TG-пост | `js/admin-core.js` (generateTGPost) | ~100 строк |
| Вспомогательные | `js/utils.js`, `js/pricing.js` | ~150 строк |

Всё это копируется/адаптируется в один HTML-файл. Нет import/export — всё глобальное (как в основном магазине).

## UI-концепция

```
┌─────────────────────────────────────────────────┐
│  🎮 Content Creator          [🔄 Обновить]      │
├─────────────────────────────────────────────────┤
│  Поиск: [____________]  Выбрано: 3/5            │
│  ┌──────────────────────────────────────────┐   │
│  │ ☑ Spider-Man 2      2 500 ₽  -30%  🖼    │   │
│  │ ☐ God of War        3 200 ₽       🖼     │   │
│  │ ☑ GTA V             1 800 ₽  -20%  🖼    │   │
│  │ ...                                      │   │
│  └──────────────────────────────────────────┘   │
├─────────────────────────────────────────────────┤
│  [🖼 Коллаж]  [📱 Сторис]  [📢 TG-пост]        │
└─────────────────────────────────────────────────┘
```

- Таблица: название, цена, скидка, миниатюра обложки, чекбокс
- Поиск фильтрует в реальном времени
- Максимум 5 выбранных (для коллажа/сторис)
- Кнопки активируются когда выбрана хотя бы 1 игра
- TG-пост: любое количество игр

## Стиль

Тёмная тема, те же CSS-переменные что в основном магазине:
```css
--bg: #0a0a16;  --card: #0e0e1c;  --border: rgba(255,255,255,.08);
--text: #e8e8f0;  --muted: #666680;  --blue: #0070d1;  --accent: #f0a020;
```
Шрифты: системные (без Google Fonts для скорости).

## 📓 Журнал самообучения (методика — скилл `bot-selflearn-log`, сессия 63, 2026-09-02)

Собирает сырьё о том, чем инструмент пользуются на самом деле и что человек переписывает за ИИ.
Смысл извлекается ПОСТФАКТУМ (`node -e` по `*.jsonl`) — никакой классификации в рантайме.

- **Куда:** `POST https://api.poigraem.shop/cc/journal` (`requireAdmin`, тот же `cc_admin_token`),
  файлы `~/cc-journal/YYYY-MM.jsonl` на VPS, ретеншн 6 месяцев, потолок события 32 КБ.
  Env: `CC_JOURNAL_DIR` / `CC_JOURNAL_KEEP_MONTHS` / `CC_JOURNAL_ENABLED`.
  Свой каталог, а не общий с `~/catalog-journal`: там 17 тыс. `archive_restored` из цикла импорта.
- **Клиент:** внутри `content-creator.html` (`jEvent` / `jError` / `jAgg` / `jFlush`) — перенос
  обкатанного `poigraem/js/journal.js`. Буфер в `localStorage.cc_journal_buf` (до 300 событий),
  отправка пачками при 20 событиях / раз в минуту / при уходе со страницы (`pagehide`,
  `visibilitychange` — важно для телефона). Без токена события просто копятся в буфере.
- **События:** `session_start`, `used{feature}`, `search`, `generated`, `edited`, `published`,
  `rejected`, `error{stage}`, `hd_ok` / `hd_miss`, `cover_replace{source}`, `slot_transform`,
  `tpl_switch`, `el_add` / `el_delete` / `el_dup` / `el_layer`, `undo`, `prop_change`.
  Имена — из общей таксономии скилла, переименовывать нельзя: на них держится метод разбора.
- **chainId** — одна работа над одним артефактом (`post-…` / `collage-…` / `story-…`), заводится
  в `openTGPost` / `openCollage` / `openStory`. В каждом событии есть `device` (mobile/desktop) и `w`.
- **Правила, которые легко сломать:** (1) не вешать события на циклы (по играм, на перерисовку
  канваса) — так утонул журнал каталога; микроправки схлопывать через `jAgg`. (2) Снимки версии
  ИИ (`_ccPostBot`, `_stShortDescsAI`, `_stCapBot`) делать в момент генерации: правка человека
  пишется в те же переменные и затирает предложение модели навсегда. (3) base64 (лого 218 КБ,
  фото товаров, PNG) в журнал не тащить — `_jTrim` глушит, но поля выбирать осознанно.
